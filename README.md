# Frontend for Web-Based Video Editing Platform

This project is a frontend-only implementation of a **Web-Based Video Editing Platform** that allows users to:

- Upload a video
- Add titles or captions
- Modify audio
- Overlay text/images
- Simulate rendering and downloading the final video

## Live Demo

[Click Here:](https://video-editing-platform-1f02x61zf-codewithmanas-projects.vercel.app/)

## Tech Stack

| Technology     | Purpose                             |
| -------------- | ----------------------------------- |
| Next.js        | React-based full-stack framework    |
| App Router     | Routing and layout management       |
| Tailwind CSS   | Utility-first CSS styling           |
| Redux Toolkit  | Global state management             |
| ShadCN UI      | Accessible and modern UI components |
| React Dropzone | File drag-and-drop functionality    |

## Features Implemented

### Video Upload

- Drag and drop video file
- Preview the uploaded video

### Titles and Captions

- Add title text with start and end times
- Display titles in real-time during preview

### Audio Editor (Not Implemented)

- Simulate muting video audio
- Upload background music

### Image/Text Overlay (Coming Soon)

- Upload image/text and drag onto video frame

### Timeline Editor

- Drag and rearrange video/audio/title blocks

### Render & Download (Simulated)

- Simulate rendering the final edited video
- Simulate download of processed video

## 🧪 Setup Instructions

- 1.**Clone the repository**

   ```bash
   git clone https://github.com/codewithmanas/video-editing-platform.git
   cd video-editing-platform
   ```

- 2.**Install dependencies**

```bash
    npm install
```

- 3.**Start the dev server**

```bash
    npm run dev
```

- 4.Visit: ``http://localhost:3000``
